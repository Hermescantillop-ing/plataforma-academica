## Descripción

La Plataforma Académica Básica es una página web inicial que sirve de base para un futuro
sistema académico (consulta de cursos, docentes y horarios). La finalidad del proyecto no es
desarrollar una aplicación completa, sino demostrar el flujo de trabajo colaborativo con Git y GitHub:
ramas, commits, pull request, revisión de código y fusión con `main`.

## Estructura del proyecto

```
plataforma-academica/
├── README.md
├── index.html
├── style.css
└── script.js
```

## Cómo ejecutarlo

Abrir el archivo `index.html` en cualquier navegador web.

## Flujo de trabajo utilizado

1. Rama de trabajo: `feature/estructura-inicial`
2. Commits descriptivos por cada cambio
3. Pull request hacia `main`
4. Revisión de código entre compañeros
5. Merge a `main`
